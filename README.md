# Student Management Application

## Project Description

The Student Management Application is a full-stack web application developed as a Foundation Mini Project.

The application allows users to add, view, update, and delete student records.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Axios

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL / PostgreSQL

### API Testing
- Postman

## Features

- Add Student
- View All Students
- View Student by ID
- Update Student
- Delete Student
- REST API
- Database Connectivity

## Application Workflow

React Frontend
↓
REST API
↓
Spring Boot Backend
↓
Spring Data JPA
↓
MySQL / PostgreSQL Database

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/students` | Get all students |
| GET | `/students/{id}` | Get student by ID |
| POST | `/students` | Add a student |
| PUT | `/students/{id}` | Update student |
| DELETE | `/students/{id}` | Delete student |

Open the frontend project in the terminal.
